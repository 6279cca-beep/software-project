# 소프트웨어 프로젝트 계획서

**제출자:** 김선형
---

## 1. 프로젝트 명
**참고문헌 아카이브**

## 2. 설명
방대한 양의 참고문헌을 키워드 검색을 통해 필요할 때마다 찾 수 있는 아카이브

## 3. 프로젝트 기획 배경
정치외교학과 특성상 학기마다 방대한 양의 논문을 읽게 됩니다. 하지만 과제를 위해 필요한 내용을 찾으려고 하면 해당 논문이 무슨 내용인지 정확하게 기억이 나지 않아 하나하나 열어보며 확인을 해야될 때가 많습니다. 또한 미리 정리를 해놓지 않은 경우에는 어떤 논문은 다운로드 파일에 있고, 어떤 논문은 바탕화면에 있는 등 한 번에 찾아서 보기가 어려운 경우가 많습니다. 따라서 논문을 빠르게 찾고, 필요한 내용을 확인해 바로 열 수 있도록 하는 소프트웨어를 만들고자 합니다.

## 4. 프로그램 형태
본 프로그램은 텍스트 기반의 대화형 인터페이스(CLI)로 작동하며, 메뉴 번호 입력을 통해 실행됩니다.

### 주요 기능
1. **자료 등록 및 저장:** 논문의 '제목, 저자, 키워드, 요약'과 함께 원본 파일의 경로 주소를 입력받습니다. 입력된 데이터는 'Pandas'를 통해 `references.csv` 파일에 즉시 저장됩니다.
2. **키워드 검색:** 사용자가 '달러패권','선거' 등의 키워드를 검색하면, 저장된 데이터들을 탐색하여 해당 단어가 포함된 자료만 필터링해 화면에 출력합니다. 쉼표(,)를 기준으로 검색어를 분리하여 여러 개의 키워드를 동시에 탐색할 수 있는 다중 검색 기능을 지원합니다.
3. **원본 파일 실행:** 검색된 결과 하단에 열고자 하는 파일의 번호를 입력받는 프롬프트를 제공하며, 유효한 번호 입력 시 연결된 PDF 등의 파일이 컴퓨터에 자동으로 실행됩니다.
4. **전체 목록 조회:** 현재까지 저장된 모든 레퍼런스 목록을 정렬하여 출력합니다.

## 5. 활용 문법
* **외부 라이브러리 활용:**
  * `Pandas`: 파이썬과 엑셀(CSV) 파일을 연결하여 데이터를 영구적으로 저장하고 불러오는 역할.
* **기초 문법 활용:**
  * **반복문 (`while True`):** 사용자가 종료(4번)를 누르기 전까지 메뉴 시스템을 계속 유지.
  * **조건문 (`if-elif-else`):** 사용자의 메뉴 선택 처리 및 검색어 포함 여부 확인.
  * **자료 구조 (`Dictionary`):** 개별 논문 자료의 속성(제목, 저자 등)을 키-값 쌍으로 구조화하여 다룸.
  * **입출력 (`input`, `print`):** 사용자와 상호작용하는 텍스트 기반 인터페이스 구축.
* **내장 모듈('os') 활용:**
  * 'os': `os.startfile()` 함수를 활용하여 파이썬 내부에서 윈도우 운영체제의 외부 파일을 직접 실행.
