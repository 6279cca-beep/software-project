# 소프트웨어 프로젝트 계획서

**제출자:** 김선형

## 1. 프로젝트 명
**과제 레퍼런스 아카이브**

## 2. 설명
방대한 양의 참고문헌을 키워드 검색을 통해 필요할 때마다 찾 수 있는 아카이브

## 3. 프로젝트 배경 및 기획 의도
* **문제 정의:** 정치외교학 전공 특성상 학기마다 방대한 양의 논문과 에세이 자료를 읽게 됩니다. 하지만 읽었던 자료들이 여러 폴더나 노트에 흩어져 있어 나중에 다시 찾으려면 상당한 시간이 소모되는 불편함이 있습니다. 또한 논문을 찾더라도 여러 개를 읽었다보니 어떤 내용이었는지를 제목만 보고 바로 알기 어려운 경우가 많습니다. 따라서 키워드와 내용 요약을 함께 볼 수 있도록 하여 필요한 자료를 금방 찾을 수 있도록 하고자 합니다.
* **기획 의도:** 수업 시간에 배운 파이썬의 핵심 기초 문법(조건문, 반복문 등)을 뼈대로 삼고, 외부 데이터 처리 라이브러리인 `Pandas`를 결합하여 '학습용 자료 검색기'를 개발합니다. 입력한 자료를 엑셀(CSV) 형식으로 영구 보관하고, 필요할 때 키워드 하나로 즉시 찾아낼 수 있는 실용적인 도구를 만드는 것이 목표입니다.

## 4. 프로그램 형태
본 프로그램은 텍스트 기반의 대화형 인터페이스(CLI)로 작동하며, 직관적인 메뉴 번호 입력을 통해 실행됩니다.

### 주요 기능
1. **자료 등록 및 자동 저장:** 논문의 '제목, 저자, 키워드, 한 줄 요약'을 입력하면 프로그램이 이를 데이터로 묶어 `references.csv` 파일에 즉시 저장합니다.
2. **키워드 검색:** 사용자가 '달러패권','선거' 등의 키워드를 검색하면, 저장된 데이터들을 탐색하여 해당 단어가 포함된 자료만 필터링해 화면에 출력합니다.
3. **전체 목록 조회:** 현재까지 저장된 모든 레퍼런스 목록을 보기 좋게 정렬하여 출력합니다.

### 작동 알고리즘 흐름
1. 프로그램 시작 시 무한 루프(`while True`)를 통해 메인 메뉴 출력.
2. 사용자 번호 입력(`input`) 대기.
3. 입력된 번호에 따라 `if-elif` 분기를 통해 각 기능(등록/검색/조회/종료) 실행.
4. '등록' 기능 실행 시 딕셔너리 형태로 데이터를 받아 `Pandas`를 통해 CSV 파일의 새로운 행으로 추가.
5. '검색' 기능 실행 시 CSV 파일의 데이터를 순회하며 조건(`if keyword in data`)에 맞는 결과만 `print` 함수로 리포트 형식 출력.

## 5. 활용 문법
* **외부 라이브러리 활용:**
  * `Pandas`: 파이썬과 엑셀(CSV) 파일을 연결하여 데이터를 영구적으로 저장하고 불러오는 핵심 엔진 역할.
* **기초 문법 활용:**
  * **반복문 (`while True`):** 사용자가 종료(4번)를 누르기 전까지 메뉴 시스템을 계속 유지.
  * **조건문 (`if-elif-else`):** 사용자의 메뉴 선택 처리 및 검색어 포함 여부 확인.
  * **자료 구조 (`Dictionary`):** 개별 논문 자료의 속성(제목, 저자 등)을 키-값 쌍으로 구조화하여 다룸.
  * **입출력 (`input`, `print`):** 사용자와 상호작용하는 텍스트 기반 인터페이스 구축.
